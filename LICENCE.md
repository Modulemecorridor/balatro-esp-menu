## 🧩 About

**Balatro Companion** is a curated list of Balatro open-source tools:

- **Overlays** — on-screen helpers, layout notes, hand tracker, chip counter
- **Quality-of-Life Helpers** — card catalog, deck manager, synergy notes
- **Research Notes** — probability tables and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Hand Tracker — log played hands and remaining deck composition
- Chip Counter — display current chips and multiplier breakdown
- Blind Timer — track upcoming blinds and boss effects
- Playback Speed — adjust game speed for study (0.5x to 3x)

### Wallhack
- Card Catalog — browse jokers, tarot cards, and planet cards
- Deck Manager — organize custom deck configurations
- Synergy Notes — save and review joker synergy combos

### Aimbot
- Probability Table — view draw odds for remaining cards
- Boss Blind Notes — study boss blind effects and counters
- Seed Viewer — inspect and share run seeds for practice
